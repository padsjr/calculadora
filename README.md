Projeto para firnmar a lógica: variaveis, condicionais, laços e funções

Inicialmente fiz um codigo simples para ler dois numeros e realizar uma operação entre eles exibindo o resultado

Efetuei o tratamento de erro para divisão por zero

Montei um menu para realizar as operações pelo terminal

Para massificar o conhecimento, cada operação com encapsulada em uma função diferente e foi feito também o tratamento das exceções e validação das entradas

Ao fim como desafio extra, foi implementado o codigo, para que fosse possivel realizar o encadeamento de calculos com os resultados anteriores

O sistema é capaz de realizar operações de soma, multiplicação, divisão, subtração entre dois numeros, o sistema permite ainda ao usuario, realizar novas operações com o resultado obtido

Fluxograma do sistema

Sistema solicita um valor, armazena, Sistema solicita um operador, armazenta, sistema solicita o segundo valor, armazaena, Sistema verifica o operador selecionado, executa operação, exibe ao usuario e questiona se gostaria de realizar, nova operação, continuar com o resultado em uma nova operação, ou finalizar o sistema
